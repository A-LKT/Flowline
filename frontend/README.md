# Flowline — Frontend

React 19 + Vite + ReactFlow client for Flowline. See the repository root
[README.md](../README.md) for setup, and [DOCS.md](../DOCS.md) for the user guide.

```bash
npm install
npm run dev     # Vite dev server (proxies the API to the backend on :3001)
npm run build   # type-check + production build to dist/
```
